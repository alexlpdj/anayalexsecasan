# Audio Files

Coloca tu archivo de música de boda aquí con el nombre 'wedding-music.mp3'

Formatos soportados:
- MP3 (recomendado)
- WAV
- OGG

Ejemplo: public/audio/wedding-music.mp3

Puedes usar música libre de derechos de:
- https://www.bensound.com/
- https://incompetech.com/
- https://freemusicarchive.org/
